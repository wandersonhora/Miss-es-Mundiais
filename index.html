    Como atualizar os dados

    Todo o conteúdo do app vem de dois arquivos simples, em data/countries.json e data/missionaries.json. Para atualizar:

    1. Edite os arquivos JSON com os novos números (nova Lista Mundial da Perseguição, novos dados do Joshua Project, novos pedidos de oração dos missionários).
    2. Publique novamente a pasta no Netlify (arrastando a pasta atualizada em app.netlify.com, ou via netlify deploy --prod).
    3. O app sempre exibe a data/hora atual e a data em que os dados foram gerados, deixando claro se está atualizado.

    ⚠️ Este é um painel informativo mantido manualmente. Ele não busca dados novos sozinho pela internet — a atualização depende de alguém revisar as fontes originais periodicamente (recomendado: mensalmente para missionários, anualmente para dados de perseguição e religião, que mudam pouco).
